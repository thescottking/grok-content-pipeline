# Example article folder (from the original owner, private details removed)

This is a real folder from the original owner's pipeline. It's the research pillar "What AI search engines see on 3,877 B2B software websites", published Oct 30 2026. It's here so you can see what each step leaves behind. Treat it as an example, not a template.

Removed or replaced: the owner's name (now "Owner" or `<author>`), CMS post and media IDs, editor draft URLs, X and LinkedIn post URLs and handles, agent IDs, internal research paths, a brand-identifying Search Console query, box-internal notes, and the audit price. The article text, the live site URLs in the article and link plan, and the research numbers are as published.

| File | Step |
|---|---|
| research/findings.md, research/data.csv | 1 Research (every number with denominator, date, caveat) |
| outline.md | 2 Outline |
| hooks.md | 3 Search check (search section only; the X hooks section was removed) |
| article.md | 4 Draft |
| factcheck.md | 4b Fact-check (56 claims, 0 fail) |
| links.md | 6 Internal links |
| status.md | Every handoff with a timestamp (outline 9:26 AM to live 11:56 AM CDT) |
| time-log.md | Rebuilt from status.md in the v1.1 format (minutes not recorded then) |
| performance.md | 7-day search and social readback |

Images and WordPress build files aren't included, to keep the package small.
